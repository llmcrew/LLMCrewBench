# Чек-лист приёмки клипа

Короткий список перед тем, как отдать клип в монтаж. Проверяется на пилотном
клипе каждой сцены, а не на всём наборе.

## Файл

- [ ] длительность ровно `secs` (штатно 23 с: ход из занавеса, окна и возврата),
      `ffprobe` не округляет; окно показа - 20 с;
- [ ] кадров ровно `secs × fps` (23 × 120 = 2760), кратно ходу и кадру показа;
- [ ] `h264`, `yuv420p`, разрешение проекта (1920×1080), две полосы 960;
- [ ] паспорт `.capture.json` рядом: `png`, все кадры сняты, часы без разрывов;
- [ ] размер < 100 МБ (потолок GitHub), шумное зерно пережато;
- [ ] нет звуковой дорожки, если ролик без звука.

## Картинка

- [ ] на 1-й секунде и на последней - сцена, объекты в кадре;
- [ ] нет чёрных/белых вспышек, нет кадра с курсором и UI-плашкой страницы;
- [ ] уникальных кадров больше одного (или статичность объяснима замыслом);
- [ ] нет «половины кадра»: canvas растянут, поля залиты краями сцены;
- [ ] при нескольких canvas показывается сцена, а не пустой декой.

## Сетка и статусы

- [ ] полосы без зазоров накрывают кадр, занавес 0,75 с и он половина лида;
- [ ] ходы не перекрываются: `layout.storyboard_errors` пуст;
- [ ] `ok`-клип не чёрный, плашка чёрная; статус из `timing.STATUSES`;
- [ ] `ok` без маркера, плашка с маркером того же статуса;
- [ ] починка из `_repairs` записана с `repaired`, исходник не тронут;
- [ ] `result-notes` ссылаются на пары манифеста, провал без правки кода не
      открывается на весь кадр.

## Драйвер

- [ ] `__ready` выставлен, `__probe()` отвечает объектом;
- [ ] `freeze` стабилен между прогонами (сцена детерминирована);
- [ ] `--mode steps` даёт ту же картинку, что драйвер;
- [ ] `seek` не упирается в конец окна: последний кадр - конец сцены.

## Пакет

- [ ] повторный запуск без `--force` идёт в `cached`, с `--force` перезаписывает;
- [ ] упавшая страница даёт `.missing` и тёмный клип, а не чёрный кадр;
- [ ] `verify_clips --manifest clips.json` зелёный, `recording-quality.json` без
      провалов;
- [ ] после прогона нет живых Chrome и пустых `_frames`;
- [ ] `find clips -size +100M` пусто.
